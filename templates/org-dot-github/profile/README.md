# OL-Platform

Nền tảng logistics/supply-chain theo kiến trúc microservices: quản lý kho, hàng hóa, đơn hàng, giao vận, tích hợp Camera AI, robot, IoT và đối tác.

| Repo | Vai trò |
|---|---|
| `ol-handbook` | Kiến trúc, hướng dẫn từng bước, runbook |
| `ol-web-admin` | Frontend quản trị |
| `ol-bff` | Backend-for-Frontend |
| `ol-iam-service` | Quản lý danh tính và phân quyền |
| `ol-warehouse-service` | Service nghiệp vụ kho (mẫu) |
| `ol-node-kit` | Thư viện dùng chung |
| `ol-build-tooling` | Dockerfile và workflow build tập trung |
| `ol-infra` | Hạ tầng (Terraform), cấu hình và triển khai |
